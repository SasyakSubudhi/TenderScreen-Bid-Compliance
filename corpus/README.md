# Evidence corpus
This is a historical closed-tender teaching screen, not legal advice or a live procurement tool.
The selected real published tender uses e-Wizard, not CPPP. This is an explicit corpus-source deviation from the suggested CPPP route; obtain instructor confirmation at Evaluation 1.
PDFs are downloaded official documents or page extracts of an official compendium. manifest.json records sources, original PDF page numbers, dates and hashes.
clauses.json contains exact whitespace-normalised PDF text, not generated legal prose. Tests require every clause text to occur on its cited local PDF page.
The GFR snapshot is the original 2017 version, NOT a consolidated 2026 rulebook. It does not establish a current startup EMD exemption. Startup EMD cases therefore escalate for policy-version review. The September 2016 order is reproduced on original PDF page 235 (printed page 209) of the official DPE compendium; the local extract has that page at page 1.
The July OM carries extraction noise in the MSE paragraph; the original PDF remains authoritative. No assertion of automatic MSE turnover waiver is made.
Full procurement chapter extraction uses 1100-character windows and 150 overlap. Live tools search a separately indexed, curated clause collection so each decision cites an intact rule with preserved conditions. This limited scope needs human curation when adding tenders.
